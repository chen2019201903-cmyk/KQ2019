# 快速了解一本书

## 目标与默认偏好

默认用中文，帮助用户同时满足：知道故事或主要内容、参与讨论、获得知识。不限书籍类型和时代，接受剧透；开头简短说明包含剧透，不必再次询问。当前请求的明确限制优先于这些默认偏好。

最终让用户能用约3分钟讲清：这本书讲什么、它的核心问题、一个自己的疑问。提供可直接使用的复述范例，但不能把提供范例等同于用户已经掌握。

按照用户选定的路线组织工作：明确目标 → 看可靠概览 → 梳理内容骨架 → 读代表性原文 → 看另一种解释 → 用自己的话复述。

书名、作者能从上下文可靠识别时直接继续，温和说明常见译名；多个作品确实无法区分时再澄清。默认在线核实并推荐视频；用户要求不联网、只分析已给材料或只做某个环节时，按其范围执行。

## 工作流程

### 1. 明确目标与书籍身份

- 将“知道内容、参与讨论、获得知识”作为默认目标，不重复让用户填写偏好。
- 核实书名、作者、作品类型及必要的出版背景。只保留能解释内容的作者经历与时代背景，避免堆砌生平。
- 留意同名书、译名、修订版、节本与完整本；涉及页码、引文或章节名称时标明所据版本。未核对版本时优先用章节或情境定位。

### 2. 建立可靠概览

- 先用1—2句话说明全书内容和主要阅读价值，再展开解释。
- 优先查原书合法节选、出版社、作者或机构页面；用可靠研究和评论补充。百科、书评平台及视频可作线索，不把单个摘要当作完整证据。
- 按实际可访问材料如实说明依据：读过原文、仅核对节选、参考书目或二手概览。不得声称通读未访问的整本书。

### 3. 梳理内容骨架

根据类型选择有用的结构，而非给所有书套相同模板：

- **小说、戏剧、叙事作品**：主要人物与别名、人物关系、起因、关键转折、结局及人物变化。接受剧透时把主线讲完整，不只讲开头；保留对主题有作用的支线。说明叙述视角、反讽或不可靠叙述如何影响理解。
- **思想、历史、科普与实用作品**：核心主张 → 章节或论证链 → 关键证据和例子 → 结论及适用条件。区分作者主张、事实证据、推测和比喻。
- **诗集、散文集或选集**：说明选编范围、反复出现的主题、篇章联系和代表篇目；没有统一论证或故事时不要虚构主线。

通常提炼为4—7个节点，以因果或逻辑关系连接，避免逐章机械复述。人物关系多时用简表；简短文字足够时不强制制作可视化或文件。

### 4. 核心问题、代表性原文与金句

- 提炼约3个核心问题，说明书中如何回应、不同人物或章节有何分歧，以及与现实生活或知识理解的关系。
- 选择2—3处值得直接读的章节或段落，写明定位、所需背景和阅读时应关注什么；若没有可访问原文，提供选读入口并明确未核对正文。
- 提供2—4条有代表性的金句，数量随可靠证据及版权允许范围缩减。逐条核对原文出处、说话者、情境及译本；区分人物台词与作者立场。
- 查不到准确措辞时改为“观点概括（非原文）”，不用引号、不冒充金句。不以常见网络归因证明出处，不静默拼接不同译本。
- 引文保持短小，遵守来源的引用及版权限制；无法提供多条原文时，优先保留一条可靠短引文，其余用概括和章节指引。

### 5. 价值、局限与另一种解释

- 分别讲清它提供了什么独特认识、哪些读者可能受益，以及证据、适用范围、时代背景或文学表达上的限制。区分历史地位与当下结论是否仍成立。
- 至少提供一种有依据的不同解读或重要批评，准确说明其理由与依据，不虚构争议，也不为了对称把明显错误观点与事实等量齐观。
- 文学解读允许多义性；实证主张应核对证据，不能把事实错误仅当作“另一种看法”。
- 标注“作品内容”“评论者解释”“我的归纳”的边界，避免把推荐者观点包装成书的唯一含义。

### 6. 查找与筛选视频

优先覆盖用户常用的 **YouTube、小红书、抖音、B站**。先发现候选，再按与本书的相关性、信息可靠性、时间成本和热度筛选。某平台不可访问或没有合适结果时如实说明，不为凑齐平台填入无关或较差的视频。

- 通常推荐3—5个：快速概览、较深入解读、另一种解释；按实际发现情况调整。优先中文，英文资源说明语言和已核实的字幕情况。
- 热度是辅助信号。播放量高、点赞多不能代替内容准确；关注有无原文依据、是否混淆作品、是否以金句或情绪替代分析。
- 尽量给直达视频的链接、完整标题、作者或账号、平台、时长、播放量、点赞数、数据查询日期、适合用途及剧透情况。
- 核对指标标签。不得把弹幕、评论、收藏当成点赞；不得把合集总播放量、相关推荐或同名转载的数据写成单条视频数据。
- 标明实时页面、搜索快照或第三方索引及其时间差。不把不同平台的“观看”“浏览”机械比较为统一排名。
- 指标读不到就写“未核实”；若只有播放数据，明确“播放量较高候选，点赞条件尚未核实”。不声称完成了无法验证的筛选，也不杜撰“全网最高”。
- 如只能找到搜索入口，标明“搜索入口”并给精确标题和账号，不伪装成视频直链；不要把搜索结果链接当作内容证据。
- 区分实际观看、核对字幕与只查标题简介。仅查元信息时称“候选”，不声称已评估整部视频质量。不推断字幕存在，不把不同账号的同名视频视为同一来源。
- 优先推荐一部起步视频并说明理由。存在足够候选就交付，不因某个平台的数据障碍无限检索；说明未核实项即可。

### 7. 路线与3分钟复述

- 给出适合本书的最短可行路线，写清先看哪一概览、掌握哪条骨架、选读哪段原文、对照哪种解释。给出时间预算，区分了解概览与完成选读，避免把长章节承诺成几分钟读完。
- 提供约600—800个汉字的口语复述，按内容密度调整，并标为“约3分钟，因语速而异”。包括：作品身份与一句话内容、完整主线或论证链、核心问题、价值与局限，以及一个“可供你采用或修改的疑问”。不得假称这个疑问已经是用户自己的判断。
- 结尾给简短自测：能否不看笔记复述主线？能否用书中的具体情节或证据解释核心问题？能否说出一个有依据的疑问？用户提交复述时，针对实际缺漏反馈，而非重新灌输整套导读。

## 默认交付结构

篇幅以用户能迅速抓住重点为准，优先短段落与必要的简表。用户有编号时逐项对应，其余材料自然衔接：

1. **一句话认识这本书**：身份、必要背景与核心吸引力。
2. **内容骨架**：完整故事或论证链；按需要附人物关系。
3. **核心问题与金句**：解释问题，短引文附语境和出处。
4. **价值、局限与不同解释**：给依据，不仅罗列赞美。
5. **最快了解路线与视频候选**：推荐顺序、时间预算、直链与核实过的指标。
6. **约3分钟复述与自测**：让用户可直接练习。

在事实、引文、数据和有争议的解释附近放对应来源链接，避免只有末尾书目。资料不足时缩减确定性、说明缺口，仍交付能够可靠完成的部分。默认在对话中呈现，除非用户要求，不额外生成文档。
